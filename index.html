About Me

단순히 코드를 짜는 것에 그치지 않고, 화면 입력값, API 요청, DB 데이터, 응답 결과가 화면에 반영되는 과정을 종합적으로 추적하며 문제를 해결합니다. 에러가 발생했을 때 데이터가 어느 구간에서 어긋났는지 파악하는 습관이 있습니다.

⚙️

기획부터 배포까지 연결하는 서비스 이해도

기능 단위 구현에만 머무르지 않고, DB 설계부터 API 구현, 화면 연동, 배포 흐름까지 함께 고려합니다.

WithDay에서는 일정 탐색, 참여 신청, 위시리스트 상태가 서버 데이터와 어긋나지 않도록 API 연동 흐름을 정리했습니다.

🤝

협업과 사용자 흐름을 고려한 개발 태도

팀 프로젝트에서 팀장 역할을 맡으며 기능 구현뿐 아니라 역할 분담, 일정 관리, 사용자 흐름 개선을 함께 조율했습니다.

WithDay에서는 모바일 환경에서도 일정 카드와 탐색 화면이 깨지지 않도록 반응형 UI를 정리했습니다.

WithDay

여행, 식사, 문화생활 등 다양한 일정을 만들고 함께할 사람을 모집할 수 있는 일정 동행 플랫폼입니다.
사용자는 일정을 탐색하고 참여를 신청할 수 있으며, 호스트는 신청자를 승인하거나 거절할 수 있습니다.

주요 기능

  • 조건 기반 일정 탐색 및 일정 생성·관리
  • 참여 신청 및 호스트 승인·거절
  • 참여중·신청중·호스팅 탭 구분 관리
  • 위시리스트 및 추천 일정 조회
  • OneSignal 기반 브라우저 푸시 알림

담당 역할

  • 팀장으로 화면에서 필요한 데이터와 요청·응답 기준을 함께 정리하며 REST API 명세서 작성
  • 참여 신청 기능에서 모집 상태 확인, 정원 초과 여부 확인, 중복 신청 방지 흐름 설계
  • ParticipationController는 요청 수신에, ParticipationService는 검증과 상태 저장에 집중하도록 책임 분리
  • 신청 완료 후 NotificationService를 통해 알림 처리가 이어지도록 구성
  • React Query 기반 탭별 일정 데이터 조회, 캐시 분리, 화면 상태 동기화 처리
